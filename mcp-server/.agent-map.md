# MCP Server

Model Context Protocol server exposing CRM actions as tools for external AI models.

## Critical Files
- `src/index.ts`: MCP server bootstrap and stdio transport connection.
- `src/client.ts`: Authenticated API client calling WA-CRM endpoints.
- `src/tools/read.ts`: Tool handlers for querying contacts and conversations.
- `src/tools/write.ts`: Tool handlers for sending messages and updating deals.

## Dependencies
- `@modelcontextprotocol/sdk`, `zod`
