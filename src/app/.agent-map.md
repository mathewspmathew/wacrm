# App Router Root

Entry point and root layout configurations for the Next.js application.

## Critical Files
- `layout.tsx`: Root HTML layout, font setup, theme provider, and i18n wrapping.
- `page.tsx`: Root redirect directing visitors to inbox or login.
- `globals.css`: Global Tailwind CSS rules and theme variables.

## Dependencies
- `@/components/layout`, `next-intl`, `@/lib/supabase`
