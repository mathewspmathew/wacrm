# Authentication Pages

Public authentication routes and session lifecycle management pages.

## Critical Files
- `login/page.tsx`: User login interface with password and OAuth flows.
- `signup/page.tsx`: New user registration and onboarding view.
- `forgot-password/page.tsx`: Password recovery email trigger form.
- `layout.tsx`: Centered card layout for authentication flows.

## Dependencies
- `@/hooks/use-auth`, `@/components/ui`, `next-intl`
