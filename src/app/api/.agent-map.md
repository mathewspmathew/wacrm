# App API Routes

Next.js Route Handlers exposing backend REST API and webhook endpoints.

## Critical Files
- `whatsapp/route.ts`: Meta WhatsApp Cloud API webhook ingestion and status handler.
- `account/route.ts`: Organization and team profile management endpoint.
- `v1/`: Public API v1 endpoints guarded by API keys.

## Dependencies
- `@/lib/supabase/server`, `@/lib/auth`, `@/lib/whatsapp`, `@/lib/api-keys`
