# Dashboard App Routes

Authenticated CRM application dashboard viewports and feature route segments.

## Critical Files
- `layout.tsx`: Gated authenticated dashboard layout shell with navigation.
- `inbox/page.tsx`: Real-time WhatsApp inbox and messaging interface.
- `contacts/page.tsx`: Contact directory, segmentation, and bulk actions.
- `automations/page.tsx`: Automation workflows management and builder.

## Dependencies
- `@/components/layout`, `@/hooks/use-auth`, `@/lib/supabase`
