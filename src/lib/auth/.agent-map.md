# Auth Library

Authentication helpers, role ranking, and API request security context builders.

## Critical Files
- `roles.ts`: Pure role hierarchy definitions (`owner` > `admin` > `agent` > `viewer`).
- `api-context.ts`: Server-side context builder resolving calling user and role.
- `account.ts`: Workspace resolution and active tenant selection helpers.

## Dependencies
- `@/lib/supabase/server`, `@/types`
