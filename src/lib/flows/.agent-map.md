# Flows Engine

Multi-step chatbot graph engine executing WhatsApp interactive menus and variables.

## Critical Files
- `engine.ts`: State machine running user sessions across flow nodes and edges.
- `types.ts`: Discriminated unions for node configurations and flow run events.
- `edges.ts`: Edge resolution and conditional transition evaluate logic.

## Dependencies
- `@/lib/whatsapp`, `@/lib/supabase/server`, `@/types`
