# Supabase Clients

Configured Supabase client factories for browser, server components, and route handlers.

## Critical Files
- `client.ts`: Browser-side Supabase client using cookie-based auth tokens.
- `server.ts`: Server-side Supabase client utilizing Next.js `cookies()`.

## Dependencies
- `@supabase/ssr`, `@supabase/supabase-js`
