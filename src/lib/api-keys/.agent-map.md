# API Keys Library

Generation, hashing, scope enforcement, and revocation for external REST API tokens.

## Critical Files
- `keys.ts`: Secure token generation, SHA-256 hash comparison, and prefixing.
- `scopes.ts`: Granular permission scope definitions (`contacts:read`, `messages:send`).
- `store.ts`: Database repository queries for API key records.

## Dependencies
- `@/lib/supabase/server`, `@/types`
