# Automations Engine

Trigger-action automation engine processing message keywords, tags, and timeouts.

## Critical Files
- `engine.ts`: Core runtime executing sequential automation steps on CRM events.
- `builder-tree.ts`: Validation and graph traversal helpers for automation workflows.
- `admin-client.ts`: Elevated database client for background trigger processing.

## Dependencies
- `@/lib/supabase/server`, `@/lib/whatsapp`, `@/types`
