# Webhooks Library

Outgoing webhook dispatch system delivering signed CRM events to external URLs.

## Critical Files
- `deliver.ts`: HTTP POST delivery worker with HMAC-SHA256 signature headers.
- `endpoints.ts`: Database access for active webhook endpoint subscriptions.
- `events.ts`: Event catalog and payload formatting for external dispatch.

## Dependencies
- `@/lib/supabase/server`, `@/types`
