# Dashboard Library

Analytics query builders and aggregation routines for CRM overview metrics.

## Critical Files
- `queries.ts`: Supabase aggregate queries for messages, leads, and conversions.
- `date-utils.ts`: Time-window bucketing and date range filter helpers.
- `types.ts`: Analytics response schemas and trend data contracts.

## Dependencies
- `@/lib/supabase/server`, `@/types`
