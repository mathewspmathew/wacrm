# Contacts Library

Contact deduplication, CSV bulk ingestion, and contact-tag resolution services.

## Critical Files
- `dedupe.ts`: Phone number normalization and duplicate contact detection.
- `parse-contact-csv.ts`: Streaming CSV parser with validation for imports.
- `resolve-import-tags.ts`: Tag creation and linking for imported batches.

## Dependencies
- `@/lib/supabase/server`, `@/types`
