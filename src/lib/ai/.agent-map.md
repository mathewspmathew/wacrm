# AI Engine Library

AI model integration supporting OpenAI and Anthropic for auto-replies and knowledge RAG.

## Critical Files
- `auto-reply.ts`: Inbound message auto-reply pipeline and handoff coordinator.
- `chunk.ts`: Text chunking utilities for RAG vector embeddings.
- `types.ts`: Provider-agnostic AI interfaces, chat turn structures, and configs.

## Dependencies
- `@/lib/supabase/server`, `@/lib/whatsapp`
