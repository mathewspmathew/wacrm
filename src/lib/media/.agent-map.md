# Media Library

WhatsApp inbound media downloading, audio transcoding, and blob caching.

## Critical Files
- `download.ts`: Authenticated downloader fetching media from Meta Cloud API.
- `blob-cache.ts`: Client/server caching layer for retrieved media blobs.
- `filename.ts`: MIME-type to filename and extension resolution helpers.

## Dependencies
- `@/lib/whatsapp`, `@/lib/storage`
