# WhatsApp Integration

Meta WhatsApp Cloud API client, template messenger, and broadcast scheduler.

## Critical Files
- `broadcast-core.ts`: Batch dispatch engine respecting Meta throughput limits.
- `broadcast-resume.ts`: Recovery logic resuming interrupted broadcast runs.
- `interactive.ts`: Payload formatters for WhatsApp interactive buttons and lists.

## Dependencies
- `@/lib/supabase/server`, `@/types`
