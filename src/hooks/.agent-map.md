# Custom Hooks

Custom React hooks managing client-side auth, realtime subscriptions, and audio.

## Critical Files
- `use-auth.tsx`: Auth context provider exposing profile and session state.
- `use-can.ts`: Role and permission checker hook based on current user role.
- `use-realtime.ts`: Supabase Postgres realtime subscription lifecycle manager.
- `use-presence.ts`: Team member presence polling and heartbeat manager.

## Dependencies
- `@/lib/supabase/client`, `@/lib/auth/roles`, `@/types`
