# Settings Components

Account configuration panels for WhatsApp API, AI keys, webhooks, and team roles.

## Critical Files
- `ai-config.tsx`: Form managing BYO AI provider keys and system prompts.
- `api-keys-settings.tsx`: Public API key generation and revocation interface.
- `ai-knowledge.tsx`: Knowledge base document upload and embeddings setup.

## Dependencies
- `@/components/ui`, `@/lib/auth/roles`, `@/lib/api-keys`
