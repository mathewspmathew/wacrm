# Dashboard Metrics Components

Analytical charts, metric counters, and operational feeds for the CRM overview.

## Critical Files
- `metric-card.tsx`: Metric summary card with KPI trends and indicators.
- `conversations-chart.tsx`: Historical message volume chart.
- `pipeline-donut.tsx`: Deal stage distribution chart.
- `activity-feed.tsx`: Real-time stream of CRM events and updates.

## Dependencies
- `@/components/tremor`, `@/lib/dashboard`, `@/components/ui`
