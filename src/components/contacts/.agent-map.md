# Contacts Components

Contact management UI including details, CSV imports, tags, and custom fields.

## Critical Files
- `contact-detail-view.tsx`: Contact profile inspector, history, and notes editor.
- `contact-form.tsx`: Modal form for adding and editing contact attributes.
- `import-modal.tsx`: CSV parser and field mapper for bulk contact onboarding.
- `custom-fields-manager.tsx`: Schema editor for user-defined CRM attributes.

## Dependencies
- `@/components/ui`, `@/lib/contacts`, `@/types`
