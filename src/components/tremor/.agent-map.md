# Tremor Chart Components

Lightweight chart adapters and utilities inspired by Tremor UI.

## Critical Files
- `bar-chart.tsx`: Responsive SVG/HTML bar chart visualization.
- `chart-colors.ts`: Consistent color palette tokens for charts.
- `get-y-axis-domain.ts`: Scale domain calculation helpers for data sets.

## Dependencies
- `tailwind-merge`, `@/lib/utils`
