# Pipelines Components

Kanban board and deal management components for sales pipelines.

## Critical Files
- `pipeline-board.tsx`: Drag-and-drop Kanban board representing deal stages.
- `deal-card.tsx`: Individual deal card with value, tags, and contact links.
- `deal-form.tsx`: Create and update dialog for sales opportunities.

## Dependencies
- `@/components/ui`, `@/lib/currency`, `@/types`
