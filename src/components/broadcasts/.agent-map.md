# Broadcasts Components

Multi-step wizard UI for sending bulk WhatsApp template messages to contacts.

## Critical Files
- `step1-choose-template.tsx`: WhatsApp template picker and parameter preview.
- `step2-select-audience.tsx`: Contact filter and recipient audience selector.
- `step3-personalize.tsx`: Variable interpolation and template preview.
- `step4-schedule-send.tsx`: Send rate limiter and dispatch scheduler.

## Dependencies
- `@/components/ui`, `@/lib/whatsapp`, `@/hooks/use-broadcast-sending`
