# Components Root

Shared UI components, widgets, and layout primitives across the application.

## Critical Files
- `themed-toaster.tsx`: Toast notification wrapper synced with active theme.
- `ui/`: Reusable primitive Shadcn/Radix UI components.
- `layout/`: Top navigation, sidebar, and application frame containers.

## Dependencies
- `@/lib/utils`, `@radix-ui/*`, `lucide-react`, `next-intl`
