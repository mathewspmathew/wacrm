# Inbox Components

Real-time conversation management, messaging interface, and contact sidebar.

## Critical Files
- `conversation-list.tsx`: Filterable list of active, pending, and closed chats.
- `message-actions.tsx`: Chat action buttons, template triggers, and quick replies.
- `contact-sidebar.tsx`: Contextual contact info, tags, and deal associations.
- `ai-thread-banner.tsx`: Controls for AI co-pilot status in conversation.

## Dependencies
- `@/hooks/use-realtime`, `@/lib/whatsapp`, `@/components/ui`
