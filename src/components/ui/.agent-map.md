# UI Primitives

Foundational Shadcn/Radix design system primitives and atomic elements.

## Critical Files
- `button.tsx`: Multi-variant button primitive with loading states.
- `dialog.tsx`: Modal dialog container built on Radix primitives.
- `input.tsx`: Standard text input field with error states.
- `badge.tsx`: Semantic status and categorization tags.

## Dependencies
- `@radix-ui/*`, `clsx`, `tailwind-merge`
