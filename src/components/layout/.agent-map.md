# Layout Components

Primary structural UI shell including navigation, header, sidebar, and theme switcher.

## Critical Files
- `sidebar.tsx`: Navigation menu sidebar with route indicators and badge counts.
- `header.tsx`: Global app bar with account switcher, profile, and search.
- `mode-toggle.tsx`: Light, dark, and system theme switcher dropdown.

## Dependencies
- `@/hooks/use-auth`, `@/components/ui`, `next-intl`
