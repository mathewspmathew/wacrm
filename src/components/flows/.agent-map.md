# Flows Components

Interactive visual flowchart designer for multi-turn conversational bots.

## Critical Files
- `flow-builder.tsx`: Main canvas integrating nodes, edges, and step configuration.
- `flow-canvas.tsx`: Drag-and-drop node graph canvas.
- `flow-editor-state.tsx`: State management hook for flow draft changes.

## Dependencies
- `@/lib/flows`, `@/components/ui`, `@xyflow/react`
